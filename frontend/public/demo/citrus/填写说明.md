# 陈叔贡柑：手动演示操作说明

本案例模拟一位肇庆种柑农户准备第一条卖货内容。人物、商品资料与交付安排均为演示设定；图片为提前生成的概念视觉，不代表真实农户实拍或实际交易。营销文案由 AI 提前完整创作，页面运行时原样读取整稿与固定图片，不拼接段落、不调用在线模型。

## 1. 领取图片，进入指定入口

打开本地前端首页，点击「陈叔贡柑演示」，再点击「下载演示资料包」。解压后手动上传 overall.png 和 detail.png。文件名、选择先后顺序可以改变，请不要裁剪、压缩或修改图片文件内容。

该入口只绑定本案例，不自动填写资料；不要点击原来「先看一个例子」中的预填案例。照片只在本浏览器页面会话读取，刷新或关闭后需要重填。

## 2. 填写商品资料，选择交付安排

| 字段 | 手动填写内容 |
| --- | --- |
| 产品名称 | 贡柑家庭装 |
| 类别 | 水果 |
| 产地 | 广东肇庆 |
| 怎么称呼你 | 种柑的陈叔 |
| 产品特点 | 适合家庭水果盘，也适合分给亲友 |
| 可售数量 | 60 盒 |
| 采收或上市时间 | 11 月中旬上市 |
| 售卖规格 | 3 kg / 盒 |
| 售价（只填数字） | 59 |
| 配送或取货方式 | 本地自提 |
| 可送或发货地区 | 肇庆本地约定自提点 |
| 运费说明 | 自提无运费，暂不提供配送 |
| 发货或交付安排 | 双方确认数量后，约定次日下午自提 |
| 售后处理方式 | 自提时当面核对数量和外观，发现问题及时与卖家协商。 |
| 销售范围 | 先卖给附近的人 |
| 购买用途 | 日常吃 / 日常用 |
| 先发哪里 | 微信或小红书均可，只决定内容顺序 |
| 认证 / 奖项证明说明 | 留空 |

请完整准备以上资料，包含平时可以不填的补充字段。配送方式、交付范围、运费、发货 / 自提时间和售后已改为下拉选项，选择表格中对应的一项即可；其他商品资料仍手动填写。这些内容用于核对提前制作的图文，避免展示错误的规格和承诺。文本需与参考相同，首尾空格不影响核对。售价填 59，规格填 3 kg / 盒。

## 3. 点击生成，查看四种成果

到「确认资料」点击「生成我的卖货方案」，约 1.2 秒准备进度后进入「我的卖货方案」。可以看到卖给谁、怎么介绍、补拍建议和宣传场景图。

进入「可以发布的图文」：

- 小红书：查看封面、商品介绍卡，分别下载 1080 × 1440 PNG，编辑和复制标题、正文与 6 个话题标签。
- 微信：查看并下载 1080 × 1080 朋友圈配图，编辑和复制朋友圈 / 社群文案。
- 客户咨询 / 模拟客服：点击常见问题或输入“能寄快递吗？”等顾客问题，约半秒后显示本地模拟回复；可以修改并复制。下方仍保留价格、配送、自提和售后回复草稿。
- 场景宣传图：在「我的卖货方案」下载 1440 × 1080 PNG。

固定图卡直接使用静态成品，预览和下载是同一个文件。图内文字不会随正文编辑而变化；需要改图时请另行编辑下载文件。完整方案可导出 Markdown，包含当前文字草稿、待办与图片资源清单；四张图片分别下载。

## 4. 演示发布前检查和下一步

在朋友圈文案中将 ¥59 改为 ¥99，进入「发布前检查」，可以看到价格冲突；改回 ¥59 后重新检查。不要把 99 写回商品资料作为新的演示价格。

修改商品规格、价格或照片后，原方案会显示待更新。与固定资料不符时无法套用预制图文；可修正资料，也可点击「退出固定演示，保留填写」，使用普通产品流程。普通流程保留卖货指导与浏览器 Canvas，图片使用当前上传照片。只有商品事实与三组参考资料一致时才读取 AI 预写整稿；其他资料保留空白文案编辑区，需自行填写，不套用旧文案。

准备过程中切换页面、修改资料或取消准备会终止该次任务。编辑过文案后重新生成，确认框会提示替换草稿；需要保留时先导出。

页面提供小红书和微信手动发布步骤，不登录账号或自动发布。最终由演示者在自己的账号中核对、选择图片并粘贴文案。行动清单可勾选，覆盖核对照片、运费、素材、发布与客户回复。

## 资料来源

详见 ASSETS.md。输入图片和场景图片为 AI 生成概念视觉；成品不额外叠加 AI 文字水印。对外使用时，应按发布平台的要求如实标注来源。本原型没有真实农户反馈、成交或传播效果数据。

模拟客服不接在线模型，按当前方案快照中的商品事实组织回复。缺少资料时先核实；修改商品后须先更新方案。离开该页会清空模拟对话，不读取真实客户消息或自动发送。
