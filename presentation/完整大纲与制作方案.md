# 乡创引擎：调研数据版路演完整大纲

14 页主讲，建议 5 分钟；4 页答辩附录。16:9，森林绿、暖白、柑橘橙。

## 核心主张

从公开数据说明市场与数字能力门槛，再拆解做图、文案和回复三项任务。陈叔上传贡柑照片和销售资料，AI 卖货 Agent 围绕同一份事实协调内容工具；农户核对后手动发布和沟通。

主案例：种柑的陈叔（演示人物），广东肇庆，贡柑家庭装，3 kg / 盒，¥59，60 盒，11 月中旬上市，肇庆本地约定自提。先确认数量，约次日下午来拿；当面核对数量和外观，有问题协商。

## 事实口径

主讲以 AI Agent 产品设计组织叙事。当前前端已支持手动资料输入、AI 预写完整稿和提前生成的静态图片、规则式模拟客服、规则检查和导出；在线模型和任务调度属于建设方向。图片、人物、社交发布与询盘为情境模拟，没有真实发布或成交证据。不将爆款风格写成已验证传播效果。

公开数据：2025 年全国农产品网络零售额 7833.1 亿元，同比增长 9.9%；2025 年底农村互联网普及率 69.5%；2024 年报告中农村与城镇成年人初级及以上数字素养与技能比例分别为 50.57%、65.92%，相差 15.35 个百分点；湘粤地区 528 份农户调查研究提供相关机制依据。完整来源、对象和使用限制见《数据来源与口径.md》。

### 18｜哪些已经能演示下一步验证什么

建议：答辩备用

本套保留可追问的实现边界：素材与客服目前按演示方式运行，在线 Agent 是产品建设方案。试点记录任务完成过程和使用意愿，再讨论营销效果与付费。没有真实数据的地方不填结果，不把模型接入计划当作已部署能力。

画面信息：

- 试点目标、付费方案与营销效果均需数据验证，答辩时按相应口径说明。

| 问题 | 拟采集记录 | 判断依据 |
| --- | --- | --- |
| 农户能否做完 | 完成 / 退出、求助点与代操作 | 独立完成率与失败步骤 |
| 素材是否可用 | 事实纠正、表达修改、准备时长 | 修改次数、耗时与发布意愿 |
| 发布是否有效 | 发布后平台记录、咨询与成交 | 与准备效率分开评估 |
| 合作社是否愿付费 | 服务访谈、报价反馈、购买意向 | 验证订阅与培训假设 |
| 成本能否覆盖 | 内容维护、人工审核、模型调用 | 按服务户数测算成本 |
