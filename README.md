# 乡创引擎

面向小农户的农产品营销助手。围绕“上传自家产品 → 整理销售资料 → 准备宣传图与文案 → 手动发布 → 回复客户咨询”展开。

## 本次交付

`presentation/` 内含 18 页比赛路演材料（14 页主讲、4 页附录），按 5 分钟安排：

- 可编辑定稿 PPTX：修改文字、流程与原生表格。
- 图片稿 PPTX、PDF：用于稳定播放与排版备用。
- 五分钟逐页讲稿与演示说明。
- 完整大纲、数据来源与统计口径。
- 图片版页面、模板样张、素材和图层记录。

主案例为“种柑的陈叔”销售广东肇庆贡柑家庭装：3 kg／盒、59 元、本地自提。人物、商品资料及发布情境为演示素材，不代表真实成交或试点结果。

宣传图片、吸引人的文案及咨询回复用于展示 Agent 产品方案；当前前端原型与后续在线能力的范围见附录。数据引用和口径详见 `presentation/数据来源与口径.md`。

## 使用

用 Mac WPS 打开可编辑 PPTX，放映前确认字体与页面；PDF 可作静态备用。详细操作见 `presentation/使用与编辑说明.md`。

## 前端源码

`frontend/` 包含 React、TypeScript、Vite 源码、测试、演示照片和宣传素材。需 Node.js 22.6+（建议 24）与 npm。

```sh
cd frontend
npm ci
npm run dev
```

浏览器访问终端显示的本地地址。验证命令：`npm test`、`npm run build`。详细演示流程、运行边界与素材来源见 [前端说明](frontend/README.md)。

当前为前端 Mock 演示，不包含在线模型、账号登录、自动发布或真实交易。照片仅在当前浏览器会话读取。
